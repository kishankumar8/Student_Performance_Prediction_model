In this repo I Evaluate  model that gives the prediction (using ANN ) of   Students by analyzing the past data of student .

# Student Performance Prediction using ANN

## Problem

Students ki performance ko manually predict karna difficult ho sakta hai. Different factors jaise study time, attendance aur previous performance student ke final result ko affect karte hain.

## Objective

Is project ka main objective **Artificial Neural Network (ANN)** ka use karke student ki performance predict karna hai.

## Solution

Is project me student performance dataset ka use kiya gaya hai. Data ko clean karke features ko scale kiya gaya aur ANN model train kiya gaya. Trained model student ke input data ke basis par performance predict karta hai.

## Result

ANN model successfully student performance ko predict karta hai aur model ki performance ko suitable evaluation metrics se check kiya gaya.
